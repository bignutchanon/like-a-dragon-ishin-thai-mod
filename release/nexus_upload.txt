[size=5]Like a Dragon: Ishin! — Thai Translation / ม็อดแปลไทย[/size]

[b]Full Thai translation[/b] of Like a Dragon: Ishin! (2023 remake) — 38,471 lines: main story, cutscene subtitles, NPC dialogue, substories, menus, item/weapon/skill names, encyclopedia and journal entries.

[b]What it touches:[/b] the mod is a single [b]IshinThai_P.pak[/b] dropped into [b]Content\Paks\~mods\[/b]. It does not overwrite any original game file, needs no mod loader, and is not removed by Steam's "Verify integrity of game files". To uninstall, delete that one file.

[b]Set the in-game text language to English[/b] — the Thai text replaces the English string set.
