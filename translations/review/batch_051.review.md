# batch_051 — รีวิว (คลื่น 042–054)

ชั้นงาน: พจนานุกรมในเกม (`dictionary_word_list`) · 250 คีย์ · DNT 142 (เสียงอ่านคานะ · id) · แปลจริง 108

⚠ ตารางนี้ **ต้นฉบับเป็นภาษาญี่ปุ่นล้วนทั้งช่อง EN และ JA** (ทีมอังกฤษไม่ได้แปล) จึงแปลจากญี่ปุ่นตรง ๆ

## ผลตรวจ
- ผู้ตรวจไล่นิยาม 46 คู่ที่เป็นญี่ปุ่นล้วนทั้งหมด — ความหมายถูกทุกอัน
  สำนวนที่แปลได้ดี: 知らぬが仏 = "ไม่รู้เท่ากับพระ (ไม่รู้ไม่เห็นเป็นสุข)" · 獅子身中の虫 = "หนอนในกายสิงโต (งูเห่า)"
- แก้ 1 จุด: `Corporal Traits` ใช้ "คุณลักษณะนายสิบ" ทั้งที่คำล็อก 伍長 = **สิบเอก**
  (สตริงพี่น้องที่ ship แล้วมีอาการเดียวกัน แก้ย้อนหลังด้วย)

## ด่าน C ที่ต้องแก้เครื่องมือ
ก้อนนี้ตกด่าน C ทั้งก้อนตอนแรก เพราะตัวตรวจถือว่า "อักษรญี่ปุ่นหายจากคำแปล = ทำตก"
แต่ตารางที่ต้นฉบับเป็นญี่ปุ่นล้วนต้องถอดเป็นไทยทั้งคีย์อยู่แล้ว → แก้ให้ **หายทั้งหมด = เตือน ·
หายบางส่วน = ตก** (เคสหลังคือ "มีศัพท์ญี่ปุ่นหลายคำแล้วหายไปคำเดียว" ซึ่งเป็นบั๊กจริง)
