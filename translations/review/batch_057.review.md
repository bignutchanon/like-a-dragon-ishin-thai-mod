# batch_057 — รีวิว (คลื่น 056–067 · lead ตรวจเอง)

ชั้นงาน: บทสนทนา `.msg` + บทพูด NPC · 250 คีย์ · รู้เพศผู้พูด 212 บรรทัด

## ผลตรวจ
ตกด่านอัตโนมัติ 4 จุด — **ทั้งสี่เป็นข้อบกพร่องของตัวตรวจ ไม่ใช่ของคำแปล** แก้เครื่องมือแล้วผ่านครบ 250

1. **ด่าน H (3 จุด)** — `Okami-san` (女将さん) เป็นคำเรียกตำแหน่ง ไม่ใช่ชื่อคน
   ไทยใช้คำล็อก "แม่นาง" อยู่แล้วจึงไม่มี "ซัง" ต่อท้าย → เพิ่มรายการคำเรียกบทบาทที่ยกเว้น
   (okami · sensei · danna · oyaji · nee · nii · ojou ฯลฯ) ใน `merge_qc.py`
2. **ด่าน G (1 จุด)** — บรรทัดของยามาซากิใส่ "ขอรับ" ถูกต้อง แต่ไฟล์บริบทตั้ง `neutral: true`
   เพราะช่อง `gender` เป็น unknown ทั้งที่ `speakers` ระบุผู้พูดคนเดียวและเป็นชาย
   → เพิ่มฟังก์ชัน `is_neutral()` : ผู้พูดคนเดียวที่รู้เพศ = พิสูจน์ได้ ไม่ใช่บรรทัดกลางเพศ
