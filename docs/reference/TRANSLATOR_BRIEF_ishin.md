# บรีฟนักแปล — Like a Dragon: Ishin! ม็อดแปลไทย (ISHTH)

เกม: **Like a Dragon: Ishin!** (รีเมค 2023 · Unreal Engine 4) — ญี่ปุ่นปลายยุคเอโดะ ปี 1860s
เล่นเป็น **ซากาโมโตะ เรียวมะ** ซามูไรชั้นล่าง (โกชิ) จากแคว้นโทสะ ที่ตามล่าฆาตกรผู้สังหารพ่อบุญธรรม
แล้ว **แฝงตัวเข้าหน่วยชินเซ็นกุมิที่เกียวโตในชื่อ "ไซโต ฮาจิเมะ"**

โทน: ละครพีเรียดการเมือง + ดาบ + ดราม่าพี่น้องร่วมอุดมการณ์ ตัดสลับกับเนื้อหาเสริมที่ฮาจัด
(ทำนา · ตกปลา · ย่านเริงรมย์) — **อ่านบริบทก่อนเลือกระดับภาษาทุกครั้ง**

## 2. ขั้นตอนทำงานหนึ่ง batch

1. เปิด `batch_NNN.json` **คู่กับ** `batch_NNN.context.json`
2. ดู `priority` ที่หัวไฟล์ batch ก่อน — บอกว่านี่คือบทพูดหรือข้อความระบบ:

   | priority | เนื้อหา | ระดับภาษา |
   |---|---|---|
   | 1 | บทคัตซีนเนื้อเรื่อง (รู้ผู้พูด 82%) | **ยุคบาคุมัตสึ** |
   | 2 | เรื่องย่อ/คำอธิบายเนื้อเรื่องและตัวละคร | ไทยปัจจุบัน เล่าเรื่อง |
   | 3 | เมนู/ระบบ/ไอเทม/ทักษะ/ร้านค้า | **ไทยปัจจุบัน** อ่านง่าย |
   | 4 | บทพูด NPC เดินถนน | **ยุคบาคุมัตสึ** |
   | 5 | มินิเกม/การ์ดไทชิ/โหมดถ่ายรูป | ไทยปัจจุบัน |
   | 9 (`batch_MSG_*`) | บทสนทนา ADV ทั้งเกม (ก้อนใหญ่สุด) | **ยุคบาคุมัตสึ** |

3. อ่าน context ของบรรทัดนั้นก่อนแปลทุกครั้ง:
   ```json
   "Tell me I'm wrong, Ryoma!": {
     "speakers": [{"name": "Takechi", "gender": "male", "uses": 1}],
     "gender": "male",
     "neutral": false,
     "chapters": [2],
     "ja": "違うのか！？　龍馬！！",
     "occurrences": 1
   }
   ```
4. **ดูช่อง `ja` เสมอ** — ต้นฉบับญี่ปุ่นของบรรทัดนั้นแนบมาครบทั้ง 41,601 สตริง
   อังกฤษของ RGG กลืนข้อมูลที่ภาษาไทยต้องใช้ไปเยอะ:
   - เพศผู้พูด (俺 · あたし · わし)
   - ระดับความสุภาพ (ですます vs รูปธรรมดา vs หยาบ)
   - คำนำหน้าชื่อ (〜さん · 〜殿 · 〜様) ที่อังกฤษตัดทิ้ง
   - สำเนียงคันไซ (〜や · 〜へん) ที่บอกว่าตัวละครมาจากไหน
5. `neutral: true` → **แปลกลางเพศ** (ห้ามคำแทนตัว/คำลงท้ายที่บอกเพศ) · วิธีเขียนดู PRONOUN_MATRIX §1.3
   ช่อง `why_neutral` บอกเหตุผล
6. `neutral: false` → เปิด `docs/characters.md` ที่ชื่อใน `speakers` แล้วใช้ระดับตาม PRONOUN_MATRIX §2/§3
7. `ref_tm` = คำแปลจากภาคก่อน — **ดีก็ใช้ต่อ · เพี้ยนก็เขียนใหม่**
   ⚠ **ห้ามใช้ `ref_tm` กับชื่อตัวละคร** (Ishin เป็นคนละตัวละครกับซีรีส์หลัก)
8. กรอกคำแปลลงช่อง `strings` **ทุกคีย์** (ห้ามเว้นว่าง · คงอังกฤษก็ต้องพิมพ์ค่า EN ลงไป)
9. รันตัวตรวจก่อนส่ง (ข้อ 4)

## 3. กฎงานฝีมือของภาคนี้

### 3.1 ระดับภาษา
- ตัวละครในยุค = **ข้า/ท่าน · ข้า/เจ้า · กู/มึง** (ดูตาราง PRONOUN_MATRIX §0)
  **ห้าม ผม/คุณ/ครับ/ค่ะ ในบทพูด** · คำลงท้ายสุภาพใช้ **ขอรับ / เจ้าค่ะ** (คุมความหนาแน่น ดู §6 ข้อ 1)
- ข้อความระบบ/เมนู = พูดกับผู้เล่นในปี 2026 → ภาษาไทยปัจจุบัน ปกติ
- ห้ามใส่คำสมัยใหม่ในปากตัวละคร (โอเค · ไอเดีย · เช็ก · ทีม · แฟน)

### 3.2 สำเนียง
ต้นฉบับญี่ปุ่นให้ตัวละครโทสะ/เกียวโตพูดคันไซ **ห้ามแปลงเป็นภาษาถิ่นไทย** —
สื่อความเป็นกันเองด้วยระดับสรรพนามและคำลงท้ายแทน

### 3.3 ชื่อและคำนำหน้า
- ชื่อคนญี่ปุ่นเรียง **นามสกุลก่อนชื่อตัว** ตามต้นฉบับ
- `-san`→ซัง · `-dono`→ท่าน · `-sama`→ท่าน/ซามะ · EN ไม่มี → ไม่เติม
- **เจอชื่อใหม่ที่ไม่มีใน `name_proposals.md` ห้ามตั้งเอง** — จดลง `new_names` ให้ lead

### 3.4 ความยาวและการขึ้นบรรทัด
- จำนวน `\n` ต้องเท่าต้นฉบับเป๊ะ (กล่องข้อความตัดบรรทัดตายตัว)
- ไทยยาวกว่าอังกฤษได้ ยืนยันบนจอจริงแล้วว่าไม่ล้นกรอบที่ ~29 ตัวอักษรต่อบรรทัด
  แต่ถ้ายาวเกิน 1.8 เท่าของ EN ตัวตรวจจะเตือน — เขียนให้กระชับขึ้น

### 3.5 สิ่งที่ **ไม่ต้อง** กังวลในภาคนี้
- ❌ ไม่มีข้อห้ามเรื่องตัวอักษรละตินมีเครื่องหมาย (é à ü) หรือ Cyrillic
- ❌ ไม่ต้องเลี่ยงกลิฟไทยตัวไหนเลย — สระซ้อน/วรรณยุกต์วางถูกตำแหน่งทุกตัว ยืนยันบนจอแล้ว
  (ภาคก่อน ๆ ต้องใช้ระบบ donor slot map · **ภาคนี้ไม่ใช้**)

## 5. มารยาทการแจ้ง lead

จดลงช่อง `notes` ท้ายไฟล์ done แล้วส่งพร้อมงาน — **อย่าตัดสินเอง**:
- ชื่อใหม่ที่ไม่มีในตาราง
- บรรทัดที่ context บอกผู้พูดแต่เนื้อความขัดกันชัด ๆ
- คำที่แปลได้หลายทางและกระทบทั้งเกม
- สตริงที่สงสัยว่าเป็น identifier ของเอนจิ้น ไม่ใช่ข้อความบนจอ (แปลแล้วเกมพัง)

## 6. คำตัดสินที่ปิดแล้ว (2 ก.ย. 2026) — ใช้ได้ทันที

1. **คำลงท้ายยุคเก่า = "ขอรับ / เจ้าค่ะ"** ทั้งเกม ไม่แยกตามชั้นยศ
   ⚠ **คุมความหนาแน่น** — ใส่เฉพาะบรรทัดที่ `ref_ja` ใช้รูป ですます/〜ございます จริง
   บทยาวใส่ที่ประโยคแรกกับประโยคปิดพอ · `neutral: true` ห้ามใส่เลย
   (รายละเอียด + ตัวอย่างถูก/ผิด: `PRONOUN_MATRIX.md` §4 ข้อ 1)
2. **`Domain` = "แคว้น"** · **`Bakufu` = "รัฐบาลโชกุน"** (ทั้งคู่ไม่ทับศัพท์)
3. **ชื่อตัวละคร 35 ชื่อล็อกครบ** — `translations/name_proposals.md` ขึ้น `LOCKED` ทุกแถว
   ที่พลาดบ่อย: **คนโด** (ไม่ใช่ โคนโดะ) · **ทาเคจิ ฮันเปตะ** · **นางากุระ ชินปาจิ** ·
   **อิโนอุเอะ เก็นซาบุโร** · สระเสียงยาวไม่เติม ะ ท้าย (โทชิโซ · โทโด · อิโต · อิโซ)
   ⚠ **ไซโต ฮาจิเมะ** = ชื่อแฝงของเรียวมะตอนอยู่ในชินเซ็นกุมิ — ฉากที่อยู่กับหน่วยต้องเรียก
   "ไซโต" เท่านั้น หลุด "เรียวมะ" = สปอยล์เนื้อเรื่อง
4. **สี่ท่าต่อสู้** (ญี่ปุ่นตั้งเป็น 「〜の型」 คำไทยจึงเป็น "ท่า…"):
   `Swordsman` = **ท่าดาบเดี่ยว** · `Gunman` = **ท่าปืนสั้น** ·
   `Wild Dancer` = **ท่าระบำอลวน** · `Brawler` = **ท่ามือเปล่า**
   `Swordsman Rank 7` = **ดาบเดี่ยว ขั้น 7** (ตัดคำว่า "ท่า" ออกเมื่อมีคำว่าขั้นต่อท้าย)

คำล็อกทั้งหมด 37 คำอยู่ที่ `translations/glossary.md` §1 —
`python scripts/check_glossary_locks.py` ตรวจให้ก่อนส่งงาน
