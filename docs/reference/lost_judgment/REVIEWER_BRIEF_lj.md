# บรีฟผู้ตรวจ — Lost Judgment ม็อดแปลไทย (LJTH)

> กติกาการตรวจทั้งหมด (7 ด่านของ `merge_qc.py` · วิธีเขียนรายงาน · เกณฑ์ตีกลับ) ใช้ตามบรีฟภาคแรก
> `docs/reference/REVIEWER_BRIEF_judge.md` — ไฟล์นี้เก็บเฉพาะ **สิ่งที่ต้องตรวจเพิ่มเพราะเป็นภาคนี้**

## 1. ตรวจ "เพศ + สรรพนาม" ด้วยข้อมูล ไม่ใช่ความรู้สึก

ทุก batch มีไฟล์คู่ `batch_NNN.context.json` ที่บอกผู้พูด/เพศ/บังคับกลางเพศรายบรรทัด
**ผู้ตรวจต้องเปิดไฟล์นี้** แล้วไล่สามข้อ:

| เช็ค | เกณฑ์ตก |
|---|---|
| บรรทัดที่ `neutral: true` | มี ครับ/ค่ะ/คร้าบ/จ้า · มี ผม/ดิฉัน · ระบุเพศผู้พูดในเนื้อความโดยไม่จำเป็น |
| บรรทัดที่ `gender: male` | ใช้ ค่ะ/ดิฉัน (นอกเครื่องหมายคำพูดที่ยกคำคนอื่นมา) |
| บรรทัดที่ `gender: female` | ใช้ ครับ/ผม (เงื่อนไขเดียวกัน) |
| ทุกบรรทัด | ผสมข้ามระดับ (ผม…มึง · กู…คุณ) |

รันอัตโนมัติก่อนอ่านด้วยตา:
```
python scripts/check_speaker_gender.py --files translations/done/batch_NNN.done.json
python scripts/check_pronoun_pairs.py  --files translations/done/batch_NNN.done.json
python scripts/check_latin_leftovers.py --only NNN
```

⚠ `gender_confidence: medium-conflict` = หลักฐานขัดกันแต่ตัดสินตามเสียงข้างมาก —
ถ้าบทจริงในไฟล์บอกตรงข้าม **ให้เชื่อบท** แล้วแจ้ง lead (lead แก้ที่ `harvest_gender_evidence.py`
แล้วสร้าง context ใหม่ทั้งโปรเจกต์ ไม่ใช่แก้เฉพาะ batch)

## 2. ตรวจของที่พังเฉพาะภาคนี้

1. **อักษร Cyrillic ในคำแปล** = พังบนจอ (ฟอนต์ซับใช้ช่อง Cyrillic เป็น donor ของกลิฟไทย)
   — ตกทันที ไม่ต้องถกเถียง
2. **ละตินมีเครื่องหมาย** (é ü ñ ā ō) — ตกเช่นกัน ให้เปลี่ยนเป็น ASCII
3. **ซับสองชุด (เสียง JA / เสียง EN)**: สองประโยคที่ความหมายเดียวกันแต่สำนวนต่าง **ต้องแปลทั้งคู่**
   และควรใช้คำศัพท์/ชื่อเฉพาะชุดเดียวกัน (ห้ามคำแปลชื่อคนไม่ตรงกันระหว่างสองบรรทัด)
4. **ชื่อสถานที่/ร้าน** ต้องตรงกับ `translations/glossary_seed.md` ถ้าแถวนั้นมีคำแล้ว
   (คำเหล่านี้ ship ไปแล้วในภาค Y7/Y8/K3 — ผู้เล่นคุ้นตา)
5. **ชื่อตัวละครที่ล็อกร่วมกับโปรเจกต์ JUDGMENT** (ยากามิ · ไคโตะ · ซุกิอุระ · สึคุโมะ · ซาโอริ ·
   เก็นดะ · ฮิงาชิ · มาฟุยุ) ห้ามเปลี่ยนรูปเด็ดขาด — เจอไม่ตรงให้ตีกลับ

## 3. สิ่งที่ยังไม่ freeze (อย่าตีกลับเรื่องพวกนี้ ให้รวบรวมส่ง lead)

- การอ่านชื่อ **Seiryo** · **RK** · **Boxer Style** · ชื่อบททั้ง 17 บท
- ชื่อไทยของตัวละครใหม่ที่มีบทเยอะ (`amasawa` · `kuwana` · `ehara` · `sawa` · `souma` ฯลฯ)
- ดูรายการเต็มใน `translations/glossary.md` §6

## 3.1 ก่อนเสนอ/ตีกลับเรื่องคำ ต้องค้นของเดิมให้ครบก่อน

**ห้ามเสนอคำไทยใหม่โดยไม่ค้น และห้ามตีกลับคำที่ใช้อยู่โดยไม่ค้น** — ใช้ตัวค้นกลาง:

```
python scripts/find_term.py "Ijin Three"
python scripts/find_term.py "mahjong" --max 5
```

ค้นตามลำดับ **LJ master + glossary → tm_judgment → Judgment → K3 → Gaiden → Y8 → Y7 → Pirate → K2R**

| ผลที่ได้ | ต้องทำ |
|---|---|
| มีใน **LJ master_th** | ใช้ตามนั้น จบ — คำที่ ship ไปแล้วชนะข้อเสนอใหม่เสมอ |
| ไม่มีใน LJ แต่มีใน **ภาคอื่น** | ใช้ของภาคที่อยู่สูงสุดในลำดับ + **แจ้ง lead ให้ล็อกเข้า glossary** |
| ไม่มีที่ไหนเลย | เป็นคำใหม่จริง เสนอคำไทยมาให้ lead เคาะได้ |

ที่มาของกฎนี้: sprint 10 ผู้ตรวจ batch_074 เสนอทับศัพท์ `Ijin Three` เพราะนับใน LJ ได้ 0 จุด
ทั้งที่ Y7/Y8 ล็อก "สามเจ้าอิจินโจ" และ ship ไป 64 จุดแล้ว — เขาทำถูกตามกติกาที่มีตอนนั้น
ซึ่งบอกให้นับแค่ master ของ LJ · sprint เดียวเจอคำล็อกข้ามภาคแบบนี้ **5 คำ**
(`Shintani` · `Queen Rouge` · `mahjong` · `Earth Angel` · `Ijin Three`)

## 4. รายงานผลตรวจ

รูปแบบเดียวกับภาคแรก + เพิ่มสองหัวข้อ:
- **context ที่ผิด**: บรรทัด + ผู้พูดที่ตารางบอก + หลักฐานในบทที่ขัด
- **คำที่ควรล็อก**: คำที่โผล่ซ้ำหลาย batch แต่ยังไม่มีใน glossary
