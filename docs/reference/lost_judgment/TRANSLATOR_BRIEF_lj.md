# บรีฟนักแปล — Lost Judgment ม็อดแปลไทย (LJTH)

เกม: **Lost Judgment** (PC 2021, Dragon Engine) · ทาคายูกิ ยากามิ นักสืบเอกชนจากคามุโรโจ
ลงไปสืบคดีที่โยงกับ **โรงเรียนมัธยมเซริโอ** ใน **อิเซซากิ อิจินโจ (โยโกฮาม่า)** —
คดีกลั่นแกล้งในโรงเรียน ทับซ้อนกับคดีฆาตกรรมและแก๊งวัยรุ่น **RK**
โทน: นัวร์สืบสวน + ดราม่ากฎหมาย + ดราม่าโรงเรียน + มุกจัดหนักในเนื้อหาเสริม (สลับขั้วกันคนละเรื่อง — อ่านบริบทก่อนเลือกระดับภาษา)

DLC เนื้อเรื่อง **The Kaito Files** (4 บท) เล่นเป็น **ไคโตะ** — สรรพนามคนละชุดกับตอนเขาเป็นตัวประกอบ (ดู PRONOUN_MATRIX §2.1)

> บรีฟนี้เก็บเฉพาะเรื่องของภาคนี้ · **กติกางานฝีมือทั้งหมด (การเก็บโทน · honorific · ความยาว ·
> การจัดการ tag · มารยาทการแจ้ง lead) ใช้ตามบรีฟภาคแรก**:
> `docs/reference/TRANSLATOR_BRIEF_judge.md` (อยู่ในโปรเจกต์นี้แล้ว) — อ่านครั้งเดียวให้จบก่อนเริ่ม batch แรก

## 2. ขั้นตอนทำงานหนึ่ง batch

1. เปิด `batch_NNN.json` **คู่กับ** `batch_NNN.context.json`
2. อ่าน context ของบรรทัดนั้นก่อนแปลทุกครั้ง:
   ```json
   "Well, he's been in there almost 20 minutes now.": {
     "speaker": "Yagami", "gender": "male",
     "gender_confidence": "sound_auth(talker)",
     "neutral": false, "chapter": [1],
     "bins": ["sound_auth.bin"]
   }
   ```
3. `neutral: true` → **แปลกลางเพศ** (ห้าม ผม/ดิฉัน · ห้าม ครับ/ค่ะ) · ดูวิธีเขียนใน PRONOUN_MATRIX §1.3
   ช่อง `why_neutral` บอกเหตุผล (ไม่รู้ผู้พูด / เพศพิสูจน์ไม่ได้ / ผู้พูดหลายคนใช้ข้อความเดียวกัน)
4. `neutral: false` → เปิด `characters_main.json` ที่ชื่อ `speaker` แล้วใช้สรรพนาม/ระดับที่ระบุไว้
5. `ref_tm` ใน batch = คำแปลจากภาคก่อน (Judgment ภาคแรกมาก่อนใคร) — **ดี = ใช้ต่อ** (ผู้เล่นคุ้นคำเดิม)
   **เพี้ยน = เขียนใหม่** · ⚠ `ref_tm` ไม่รู้จักผู้พูด — เช็คเพศจาก context ก่อนใช้ทุกครั้ง
6. กรอกคำแปลลงช่อง `strings` **ทุกคีย์** (ห้ามเว้นว่าง · คงอังกฤษก็ต้องพิมพ์ค่า EN ลงไป)
7. รันตัวตรวจก่อนส่ง (ข้อ 5)

## 3. กฎเหล็กเฉพาะภาคนี้

1. **ห้ามใช้อักษร Cyrillic ในคำแปล** (А-Я а-я) — ฟอนต์ซับคัตซีนของภาคนี้เอาช่อง Cyrillic
   ไปวาดกลิฟไทย จะกลายเป็นตัวไทยมั่วบนจอ
2. **ห้ามใช้ละตินมีเครื่องหมาย** (é à ü ñ ā ō œ) — ช่องพวกนี้เป็น donor ของฟอนต์เมนู
   → เขียนชื่อฝรั่งด้วย ASCII ล้วน (`Cafe` ไม่ใช่ `Café`)
3. **tag ต้องครบเป๊ะ**: `<symbol=...>` `<color=...>` `<i>...</i>` `${...}` `%s` `%d`
   · จำนวน `\n` ต้องเท่าต้นฉบับ (กล่องข้อความตัดบรรทัดตายตัว)
4. **ยากามิ = T1 "ผม" เสมอ · ห้าม "แก"/"กู"/"มึง" เด็ดขาด** — กับคนที่ไม่ควรใช้ "คุณ" ให้ใช้ "นาย" หรือเรียกชื่อ
5. **ซับมีสองชุด**: บรรทัดของคัตซีนถูกเก็บสองคอลัมน์ (ซับตอนเสียงญี่ปุ่น / ซับตอนเสียงอังกฤษ)
   เนื้อความต่างกันจริง ๆ — เจอสองประโยคที่คล้ายกันมากในคิวเดียวกัน **ไม่ใช่ความซ้ำซ้อน อย่ารวบเป็นคำแปลเดียว**
6. **ห้ามใช้คำราชาศัพท์กับตัวละครในเกม** (สืบทอดจากภาคแรก — เรื่องอ่อนไหว ห้ามเสี่ยง)
7. ชื่อเฉพาะที่ยังไม่มีในคำล็อก: ทับศัพท์ตามกฎสาย RGG (`g` กลางคำ→ก · `-ei`→เ-ย์ · `ki` ท้ายชื่อ→กิ ·
   `zu`→ซึ) แล้ว **จดใน `new_names` ท้าย batch** ให้ lead ตัดสิน — ห้ามล็อกเอง

## 4. ศัพท์ที่ต้องระวังเป็นพิเศษในภาคนี้

- **Seiryo High School → โรงเรียนมัธยมเซเรียว** (ล็อก 25 ส.ค. 2026 · 誠稜 = せいりょう)
  ⚠ `Seiryoin` เป็นชื่อคน คนละคำ ห้ามสะกดปนกัน
- **RK** = ชื่อแก๊ง — คง EN ไว้ก่อน (glossary §3)
- **ท่างู / ท่ากระเรียน / ท่าเสือ** = Snake/Crane/Tiger Style (ล็อกจากภาคแรก) ·
  **Boxer Style → สไตล์การชก** (ล็อก 25 ส.ค. 2026)
- **ชื่อบทคงภาษาอังกฤษ** (`Chapter 01: Black Sheep` ฯลฯ) — ถูกตัดออกจากคิวแล้ว ถ้าเจอหลงมาให้ใส่ค่า EN เดิม
  · แต่ **เรื่องย่อของบท** ใน `mission_title.bin` ยังต้องแปลตามปกติ
- **สำนักงานนักสืบยากามิ · สำนักงานกฎหมายเก็นดะ · โยโกฮาม่า 99** — ชื่อองค์กรต้องนิ่งทั้งเกม
- ชื่อสถานที่ในอิจินโจ/คามุโรโจ **มีคำที่ ship แล้วจากภาค Y7/Y8/K3** — ต้องเช็ค `glossary_seed.md`
  ก่อนตั้งใหม่เสมอ (126 ชื่ออิจินโจ + 124 ชื่อคามุโรโจ มีคำอยู่แล้ว)

## 4.1 คำที่ยังไม่มีคำล็อก — ต้องค้นก่อนตั้งเอง

เจอคำที่ glossary ยังไม่มี **ห้ามตั้งคำไทยเองทันที** ให้ค้นด้วยตัวค้นกลางก่อน:

```
python scripts/find_term.py "Ijin Three"
```

มันไล่ตามลำดับ **LJ master + glossary → tm_judgment → Judgment → K3 → Gaiden → Y8 → Y7 → Pirate → K2R**

- เจอใน **LJ** → ใช้ตามนั้น จบ
- ไม่มีใน LJ แต่ **มีในภาคอื่น** → ใช้ของภาคที่สูงสุดในลำดับ แล้วแจ้ง lead ให้ล็อก
- ไม่มีที่ไหนเลย → ตั้งคำเองได้ แต่ต้อง **รายงาน lead ทุกคำ**

ที่มา: sprint 10 มีคนเสนอทับศัพท์ `Ijin Three` เพราะนับใน LJ ได้ 0 จุด ทั้งที่ Y7/Y8
ล็อก "สามเจ้าอิจินโจ" และ ship ไป 64 จุดแล้ว · sprint เดียวเจอแบบนี้ 5 คำ

## 6. งบ token + มารยาททีม

- ≤120k token ต่อ batch · ห้าม subagent spawn ต่อ · ปัญหาที่ตัดสินเองไม่ได้ให้ **จดในรายงานจบงาน**
  ไม่ใช่เดาแล้วแปลไป
- รายงานจบงานต้องมี: คำใหม่ที่เสนอ (`new_names`) · จุดที่ context ขัดกับบทจริง · บรรทัดที่ไม่มั่นใจ

  (`scripts/harvest_gender_evidence.py`) แล้วสร้าง context ใหม่ให้ทั้งโปรเจกต์
